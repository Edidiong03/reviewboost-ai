# ReviewBoost AI 🚀

An AI-powered customer review collection and reputation management platform built for local service businesses.

## 🌟 Features
* **Automated Requests:** Send review requests via email and SMS after customer interactions.
* **AI Sentiment Analysis:** Analyze feedback to filter and route reviews intelligently.
* **Embeddable Widgets:** Display real-time testimonials directly on client websites.
* **Reputation Dashboard:** Track review velocity and rating trends across platforms.

## 🛠️ Tech Stack
* **Frontend:** Next.js / React
* **Backend:** Node.js / Python
* **Database:** PostgreSQL / Supabase
* **AI:** OpenAI API
